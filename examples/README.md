# COSMIC Examples

This directory contains practical examples demonstrating COSMIC's capabilities.

## Structure

### Basic Examples
- `basic_clustering/` - Simple clustering workflows
- `data_loading/` - Loading and preprocessing Gaia data
- `visualization/` - Plotting and analysis examples

### Advanced Examples
- `advanced_clustering/` - Complex clustering scenarios
- `parameter_optimization/` - Hyperparameter tuning examples
- `integration/` - Integration with external tools (Sagitta, etc.)

### Real-World Cases
- `ngc6383/` - Complete analysis of NGC 6383 cluster
- `multiple_clusters/` - Batch processing multiple clusters
- `comparison_studies/` - Comparative analysis workflows

## Running Examples

Each example directory contains:
- `README.md` - Description and instructions
- Jupyter notebooks (`.ipynb`) - Interactive examples
- Python scripts (`.py`) - Standalone scripts
- Sample data or data download instructions

## Prerequisites

```bash
pip install -e ".[examples]"
```

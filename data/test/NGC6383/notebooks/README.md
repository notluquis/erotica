# NGC 6383 notebooks

These notebooks are exploratory or historical. The paper-facing reference files
are in `../comments_paper/`.

- `legacy_experiments/`: notebooks formerly in the repo-level `experiments/`
  directory. They are NGC 6383 specific and may still contain relative paths
  from their original location.
- `workflow/`: local process/preprocess notebooks that are useful while
  developing the package or checking data products.

Before turning a notebook result into manuscript evidence, move the logic into
a script under `tools/validation/` or into reusable package code under
`cosmic/`.

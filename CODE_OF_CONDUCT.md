# Code of conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: participate in a way that would be acceptable at a research seminar. Disagreement about
methods is the point of the exercise and is welcome — including sharp disagreement, provided it is
about the work.

## Scientific conduct

Two additions specific to research software, because they are the failures that actually occur here:

- **Correct the record.** If you find that a number this package produced is wrong, say so publicly,
  including when it is your own. The repository documents its own retractions and failed approaches
  deliberately; that is the standard, not an embarrassment.
- **Claims of novelty require evidence.** "Nobody has done this" is a factual assertion held to the
  same standard as a measurement. Seven such claims have been falsified in this project's history.

## Reporting

Report unacceptable behaviour by opening a private security advisory or contacting the maintainer
directly through their GitHub profile. Reports are handled confidentially.
